How it works

01

Tokenize

Your text is split into subword tokens using the DistilBERT tokenizer — the same one used during training.

02

Classify

Tokens run through a fine-tuned DistilBERT model (trained on Civil Comments) exported to ONNX and quantized to INT8.

03

Score

Softmax probabilities give you a confidence score for each class. The higher score wins.

Built as a portfolio project. Model: distilbert-base-uncased · Dataset: google/civil_comments · Inference: ONNX Runtime (INT8 quantized, ~13ms avg)
